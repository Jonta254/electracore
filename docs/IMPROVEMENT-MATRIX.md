## Immediate verified findings

- All 280 non-assessment reading records are typed as `video` even though no playable video exists. The reader sometimes displays “Lesson”, but curriculum badges can still expose the inaccurate type. This is a factual-model defect, not a cosmetic preference.
- Navigation markup is repeated on every major route, so a shared navigation change must be introduced and tested incrementally.
- Existing storage contracts are `electracore.calc.history.v1`, `ec-progress`, `ec-completed-{courseSlug}`, and `electracore.learning.v2`.
- `LEARNING_ACCESS_MODE` remains centralised as `open-preview`.
- The repository currently has no licensed hero photograph. The flat ElectraCore mark is deterministic SVG, not instructional imagery.
- The “circuit designer” in this repository is a connected sizing/check workflow, not a freeform component-placement canvas. Public copy must describe the implementation that actually exists.
