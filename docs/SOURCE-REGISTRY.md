## Photography acceptance gate

Before an image enters the product, record its creator, original file URL, licence, download date, review date, factual alt text, instructional caption, crop notes, and technical-safety review. Store the file locally and generate responsive derivatives. Search-result descriptions such as “free to use” are not sufficient licensing evidence by themselves.
